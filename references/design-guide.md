# 设计指南：概念类科普短片

**适用范围**：解释一个概念的科普短片（哲学、心理学、认知偏误、思维模型，或者生活现象背后的一个原理），2–3 分钟讲透一个打中人的洞见，纯音乐 + 字幕，不配人声。

**这是参考，不是模板。** 每条都写了为什么，遇到不合适的题目按道理灵活调整；秒数、颜色、速度都只是例子。

文中的实测数据来自三支用这套方法做的片子：《峰终定律》（节奏慢、前 2 秒没东西，是反面教材）、《i人真的话少吗》《实践论》（按本指南改进后）。

---

## 一、选题

| | 原理类长片 | 概念类短片（本指南） |
|---|---|---|
| 回答的问题 | 它是怎么做到的？ | 我为什么会这样？这和我有什么关系？ |
| 讲的对象 | 外部的东西 | 观众自己 |
| 驱动力 | 好奇心 | 被说中的感觉 |
| 目标 | 把机制讲全讲对 | 只讲透一个洞见，不求面面俱到 |
| 时长 | 4–5 分钟，分章节 | 2–3 分钟，一气呵成 |
| 结尾 | 总结原理 | 落到观众的生活上 |

分类看**讲法**，不看题材：科学题材只要能找到一个打中人的洞见，也能这么拍。

**选题标准**（满足 4 条以上再做）：

1. 能用一句话说清这个洞见（例：“记忆不算总账”）
2. 能找到一个具体、能画出来的“东西”贯穿全片（一条曲线、一根指针、一个梨）
3. 开场能让观众自己中招，或勾起亲身回忆
4. 有可核实的实验、历史或人物，带年份和数字
5. 讲到一半能拆自己一下（转折）
6. 结尾能落到观众的生活里

**参考方向**（不是硬标准）：

- 能用一句具体的反常识问题问出来（“你的手机充到 80% 以后，为什么突然变慢了？”），观众一看就想知道答案
- 答案几步就能讲完；因果链太长的题（金融危机、通货膨胀）观众看一半就走
- “天天碰到的现象，背后藏着一个原理”是个好选题池
- 太大的概念（一整本书、一整套理论）先找里面一个具体、能打中人的切口

## 二、叙事结构（按时长比例）

```
冷开场 0–12%   第 0 帧就抓人：具体的东西 + 全片要回答的那个问题
标题   约 12%  音乐第一次重击（标题卡可留，也可以并进开头）
证据链 12–55%  实验 / 历史，人名 + 年份 + 数字
提炼   55–60%  一句话定义
转折   60–65%  拆一下自己，音乐抽空
回到你 65–88%  生活例子 + 回到开头那个东西
收尾   后 12%  自指或献词，音乐到这里才解决
```

### 前 2 秒（硬规则）

《峰终定律》抖音实测 2 秒跳出率 55.4%，首轮推荐后断流。原因：前 2 秒几乎黑屏、没有字、音量 -44 到 -55 dB，第一句字幕 3 秒才出。

- **第 0 帧三样都要有**：有内容的画面（主角占画面足够大）、字幕、可闻的声音。不从黑屏淡入
- **第一句字幕就抛出全片的核心问题**：答案留到后面。问题要具体、反常识，最好就是片名本身。也可以用一个有冲突的具体场景引出问题
- 禁的是空泛的开头：“回想一下……”“你有没有想过……”这类需要观众先配合、没有具体内容的问题
- **2 秒内必须有一次大的画面变化**：推镜头、元素爆开、数字跳出
- “空”和“静”留给标题之后的呼吸点和转折段，不放在开头

### 一物到底

- 开头那个东西全片反复出现，结尾回到它。这是“升华”的来源，不是临时加一句鸡汤
- 它是叙事上的，不是构图上的：要在不同场景、不同大小、不同形态里出现（《实践论》里的梨：被一堆卡片埋住 → 被咬一口 → 碎成颜色和形状 → 聚成一个“梨”字 → 落回手里 → 沿着螺旋往上走 → 结尾再咬一口），不能一个构图撑全场
- 题目没有实验时，用思想实验、历史故事或生活场景代替证据链

## 三、文案

- **一屏一句**：每句 12–20 字，停约 4 秒（读速约每秒 4 字，留出看画面的时间）
- **先写成能连着读的整段文案，再切成字幕**：直接一句一句写，容易碎、连不起来
- **对比句**：“不在 X，在 Y”“过日子的是一个你，记住日子的是另一个你”
- **硬数字压阵**：只用核实过的；拿不准用约数，画面和字幕说法一致（例：画面“≈70%”，字幕“将近七成”）
- **人名 + 年份**：让知识变成故事，而不是定义
- **爽点**：被说中、认知反转、数据砸脸、替你正名、笑点、悬念回收、社交货币。每 4–8 秒一个，写完数一遍
- **必须有转折**：先立住，再拆一下
- **结尾公式**：回到开头的东西 → 一句结论 → 转到“你” → 一句能截图的短句；可选自指（“这个视频，也只是一个道理”）或献词
- **关键词高亮**：每句至多 1–2 处
- **引用原文一律逐字**：名人名言、书里的话加引号就必须是原文，不凭记忆、不自己概括
- **平台敏感词**：不用“最”“第一”“官方”及其组合（最高、第一次……）

## 四、视觉语言

- **基调**：深色底、发光主角、胶片颗粒、暗角、漂浮微尘
- **单帧克制，帧间多变**：一帧里元素少、留白大；帧与帧之间变得多、变得快。匀速的缓慢漂移不算节奏
- **颜色即叙事**：每支片子定 2–3 个有含义的颜色，全片不乱用（《峰终定律》：冷蓝 = 体验，琥珀 = 记忆，珊瑚红 = 疼）
- **核心隐喻要“动”出来**：把概念变成一个视觉变化，不画静态示意图。《峰终定律》是“结尾把整条线从后往前重新染色”，一个镜头顶十句解释
- **证据用叙事化的图表讲**：面积代表总量、计时环、被选中的那条线变色
- **字体**：衬线中文（思源宋体）做标题更有质感，字幕用思源黑体；不用英文大标题
- **可读性**：画面标注不小于 18 像素；标注不和曲线、别的文字重叠；内容不压底部字幕带
- 画面全部代码绘制；每支片子按题目原创视觉，不复用上一支的动画

## 五、画面节奏

| 片子 | 大变化平均间隔 | 最长空档 | 字幕对齐率 | 超过 2 秒的静止段 |
|---|---|---|---|---|
| 峰终定律（反面教材） | 29.4 秒 | 115 秒 | 35% | 16 处，共 79 秒 |
| i人真的话少吗 | 5.4 秒 | 8 秒 | 94% | 13 处，共 44 秒 |
| 实践论 | 4.9 秒 | 16 秒（转折段） | 100% | 0 处 |

- **一句一变**：每句字幕（约 4 秒）至少一次明显的画面变化。证据段平均每 4–6 秒一次；2–3 分钟的片子准备 15–25 个不同构图
- **字幕一换，画面跟着变**：换字幕的那一刻，画面要同时变（新元素入场、数字跳、镜头推），对齐率 90% 以上
- **画面不能静止超过 2 秒**：一句字幕里至少还要有一次小律动（闪烁、跳动、逐个入场、慢推）。转折段刻意留白的除外
- **看知识，不是读知识**：把字幕遮掉只看画面，也能大致看懂这一句在说什么
- **变化手段库**：
  - 推拉镜头：从整体推近到一个点，或从一个点拉远看到全局
  - 景别切换：宏观 ↔ 微观
  - 大字报：数字、关键词全屏砸出，再退回场景
  - 变形转场：上一场的元素延展、折叠、碎裂，变成下一场的东西
  - 视角翻转：同一个东西换一种表示
  - 数据跳变：计数、柱子长高、颜色瞬间翻转
- **动静对比制造节奏**：证据段快，转折段刻意静下来；全片不能一个速度
- **画面变化卡音乐强拍**：大变化落在小节强拍
- **设计阶段就排构图**：写文案时间轴的同时，逐句写下“这句换成什么画面”

## 六、配乐与卡点

**音乐和文案共用一条时间轴：先设计卡点，再写音乐。**

| 文案节点 | 音乐动作 |
|---|---|
| 冷开场 | 第 0 秒就要有可闻的声音（有质感的音效或乐句，不从静音淡入） |
| 标题前 | 上扬音蓄力，和弦悬着不解决 |
| 标题 | 第一次重击，音乐正式进来 |
| 证据段 | 稳定脉冲，不抢字幕 |
| 关键数字 | 一记重音 |
| 概念提炼 | 往上推 |
| 转折 | 抽空到近乎安静 |
| 回到你 | 弦乐回来，情绪慢慢上来 |
| 洞见句 | 全片情绪顶点 |
| 倒数第二句 | 悬住，不解决 |
| 最后一句 | 到这里才解决 |
| 落款 | 余音，重现开头的音乐动机 |

- **速度匹配字幕**：一句字幕 = 整数个小节（120 BPM 下两小节正好 4 秒），字幕落在强拍上
- **整体 -14 LUFS**，真峰值不超过 -1 dB；用整体增益 + 限幅，不用会压缩动态的响度归一
- **安静段别太静**：转折可以抽空，但连续 10 秒低于 -35 dB，手机外放会以为坏了
- **音效克制**：重击、上扬音、重低音、嘀嗒、嗖声，加一两个和题材有关的（咬一口、拉链），全片十来次
- 用户指定了配乐时，先量出那首歌的速度和强拍，再按它排字幕

## 七、制作流程

```
选题 → 调研核实 → 视频文稿 → 前 15 秒样片 → 全曲 + 全片画面 → 抽帧质检 + 节奏质检 → 成片
```

- **前 15 秒样片**：先把开头的画面、配乐、字幕一起做出来给用户看，风格、开头那句话、节奏都在这里定
- **AI 听不见声音**：配乐好不好听由用户在样片里判断；每次渲染都跑配乐体检
- **抽帧质检必须做**：逐段出联系表，查字幕挂太久、文字重叠、元素出画、内容压字幕、数字说过头
- **节奏质检**：成片跑 `tools/rhythm.py`，以下任一项不达标就返工（转折段例外）：证据段平均间隔超过 8 秒或有 20 秒以上空档；字幕切换对齐率低于 90%；出现超过 2 秒的静止段
- 改字幕时间要同步改配乐谱子
