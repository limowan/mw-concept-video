## 一、调研（`文档/调研.md`）

### 分级

- **A**：一手来源（论文本身、原著原文、官方数据）
- **B**：二手来源（作者本人的科普文章、可靠媒体转述、教科书）
- **C**：查不到出处，**不用**

### 必查三件事

1. **原始出处**：论文标题、作者、年份、期刊；引用原文就去找原文全文逐字核对
2. **后来有没有被推翻**：专门搜这个实验后来有没有人重做、结果对不对得上、有没有反面证据。核心论点站不住就改论点，不要硬讲（例：“柠檬汁实验能测出内向”两年后重做没差别，于是把它改成开场的反转）
3. **数字的准确说法**：样本是谁、多少人、哪个条件下的数字；拿不准的用约数

### 模板

```markdown
# {主题} 调研

## 〇、立意
- 核心问题（第一句字幕）：
- 一句话答案：
- 一物到底：
- 转折：
- 结尾：

## 一、原文 / 研究

### 1. {研究名} ✅ 可用（A）
作者，“标题”，期刊 卷(期): 页码，年份。
- 发现：
- **可以说**：
- **不说**：（夸大的说法、没核实的数字）

### 2. ……

## 二、能说 / 不说

| 能说 | 不说 |
|---|---|

## 来源
- 链接……
```

## 二、视频文稿（`文档/视频文稿.md`）

### 写法

1. **先写连贯文案**：像一篇能连着读的短文，句子之间有承接
2. **再切成逐句表**：一句 12–20 字、约 4 秒
3. **每一句同时写四样**：字幕、爽点、画面怎么变、配乐和音效
4. **写完统计**：爽点密度（目标每 4–8 秒一个）、构图数量（15–25 个）

### 爽点类型

| 类型 | 例子 |
|---|---|
| 被说中 | “跟熟人是话痨，跟生人是哑巴。” |
| 认知反转 | “两年后，有人重做一遍，没差别。” |
| 数据砸脸 | “很少骑车的人里，四成多把链条画错了。” |
| 替你正名 | “你不是不会说，是说完要缓一缓。” |
| 笑点 | “下了课躲进厕所隔间，把脚抬起来。” |
| 悬念回收 | 开头埋的问题，后面给答案 |
| 社交货币 | 能截图转发的一句话（“不是我话少，是这个场子不对。”） |

### 模板

```markdown
# {主题} 视频文稿

措辞以 `文档/调研.md` 为准。

## 一、选题
- 核心问题（第 0 秒）：
- 一句话答案：
- 一物到底：（它在全片里换哪几种形态）
- 反差：

## 二、片名
- 片中标题卡：（约 12% 处砸出，可以就是核心问题）

## 三、连贯文案

（整段写，能连着读）

## 四、逐句表（一句 4 秒，约 X 分 X 秒）

| 秒 | 字幕 | 爽点 | 画面（字幕一换就变，不停超过 2 秒） | 配乐 / 音效 |
|---|---|---|---|---|
| 0 | 第一句就是核心问题 | 钩子 | 第 0 帧：主角大特写；1.5 秒一次大变化 | 第 0 秒就有声音 |
| 4 | …… | | | |
| 16 | （标题）**主题** | — | 标题砸出 | **重击**，主题进来 |

## 五、爽点统计
约 N 个 / X 秒 ≈ 每 Y 秒一个。

## 六、事实与措辞底线
- 哪些是原文、哪些是转述
- 数字的说法

## 七、敏感词自查
- 「最」「第一」「官方」：无

## 八、配乐方向
- 速度、调性、主要乐器、关键卡点

## 九、前 15 秒样片范围
```

### 检查清单

- [ ] 第 0 秒那句就是核心问题
- [ ] 标题在约 12% 处出现
- [ ] 证据段每句都写了画面怎么变
- [ ] 有一处转折（拆自己一下），音乐在那里抽空
- [ ] 结尾回到开头那个东西
- [ ] 引号里的话都是逐字原文
- [ ] 数字和调研一致，没有说过头
- [ ] 敏感词零命中
